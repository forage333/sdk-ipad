**分组**: 图片 · **SDK 方法**: `CdnUploadImgLinkIntegration`

## 简要描述

- CDN上传网络图片重置版

## 请求URL
- `{host}/wxwork/CdnUploadImgLink`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|url |是  |String |网络图片地址|
