# 5.3 修改标签

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `EditLabel`

- **请求URL**: `/wxwork/EditLabelReq`
- **参数**:

| 参数名 | 必选 | 类型 | 说明 |
|--------|------|------|------|
| uuid | 是 | String | 实例唯一标识 |
| labelName | 是 | String | 新标签名称 |
| labelid | 是 | long | 标签ID |
| groupid | 是 | long | 标签组ID |
