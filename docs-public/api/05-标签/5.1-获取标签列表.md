# 5.1 获取标签列表

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `GetLabelList`

- **请求URL**: `/wxwork/GetLabelListReq`
- **请求方式**: POST
- **参数**:

| 参数名 | 必选 | 类型 | 说明 |
|--------|------|------|------|
| uuid | 是 | String | 实例唯一标识 |
| index | 是 | int | 分页索引 |
| sync_type | 是 | int | 同步类型：1=企业标签, 2=个人标签 |
