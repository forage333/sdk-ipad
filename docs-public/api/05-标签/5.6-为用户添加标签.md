# 5.6 为用户添加标签

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `UserAddLabels`

- **请求URL**: `/wxwork/UserAddLabelsReq`
- **参数**:

| 参数名 | 必选 | 类型 | 说明 |
|--------|------|------|------|
| uuid | 是 | String | 实例唯一标识 |
| userid | 是 | long | 用户ID |
| labelid_list | 是 | []long | 标签ID列表 |
