# 13.18 语音转文字

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `SpeechToTextEntity`

## 简要描述

- 语音转文字

## 请求URL
- `{host}/wxwork/SpeechToTextEntity`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|
|msgid |是  |int |要转文字的语音消息id|
## 请求示例

```
{
    "uuid":"00000000-0000-0000-0000-000000000000",
    "msgid":1063645
}
```

## 返回示例

```
{
    "data": {
        "text": "牛牛牛牛。"
    },
    "errcode": 0,
    "errmsg": "ok"
}
```
