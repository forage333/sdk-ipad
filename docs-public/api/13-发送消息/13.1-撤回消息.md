# 13.1 撤回消息

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `RevokeMsg`

## 简要描述

- 撤回消息

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|
|msgid |是  |int |要撤回的消息id|
|roomid |是  |long |如果撤回的消息是群消息，则填写群id，联系人消息则填0|
