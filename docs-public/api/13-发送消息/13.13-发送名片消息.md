# 13.13 发送名片消息

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `SendBusinessCardMsg`

## 简要描述

- 发送名片消息

## 请求URL
- `{host}/wxwork/SendBusinessCardMsg`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|
|send_userid |是  |long |要发送的人或群id|
|isRoom |是  |bool |是否是群消息|
