# 13.8 发送大文件消息

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `SendCDNBigFileMsg`

## 简要描述

- 发送大文件消息需要走大文件上传别走cdn上传！！！！！！！！！！！！！！！！！！！！

## 请求URL
- `{host}/wxwork/SendCDNBigFileMsg`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|
|send_userid |是  |long |要发送的人或群id|
|isRoom |是  |bool |是否是群消息|
## 请求示例

```
{
    "uuid":"1688d599424",
    "send_userid":78d5913738,
    "cdnkey":"xxxx",
    "md5":"9c2e8389567e170012d3511166000151",
    "file_name":"2f0ecd499b93bd9cb0da022.zip",
    "fileSize":314065,
    "isRoom":false
}
```
