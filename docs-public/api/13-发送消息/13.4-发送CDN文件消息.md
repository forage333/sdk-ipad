# 13.4 发送CDN文件消息

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `SendCDNFile`

## 简要描述

- 发送CDN文件消息

## 请求URL
- `{host}/wxwork/SendCDNFileMsg`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|
|send_userid |是  |long |要发送的人或群id|
|isRoom |是  |bool |是否是群消息|

## 请求示例

```
{
    "uuid":"00000000-0000-0000-0000-000000000000",
    "send_userid":7881302555913738,
    "cdnkey":"xxxx",

    "file_name":"111.txt",
    "fileSize":2813,
    "isRoom":false
}
```
