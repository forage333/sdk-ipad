# 3.6 设置是否自动同意

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `AutomaticConsent`

## 简要描述

- 设置是否自动同意

## 请求URL
- `{host}/wxwork/AutomaticConsent`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

| 参数名 | 必选 | 类型   | 说明                                         |
| :----- | :--- | :----- | -------------------------------------------- |
| uuid   | 是   | String | 每个实例的唯一标识，根据uuid操作具体企业微信 |
## 请求示例

```
{
    "uuid":"bc48e30d0c00492083fdec4c1a7e5c94",
    "state":1 //1 是需要验证同意（需要手动点击同意） 0关闭验证 自动同意好友
}
```

## 返回示例

```
{
    "data": null,
    "errcode": 0,
    "errmsg": "ok"
}
```
