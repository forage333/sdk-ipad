# 2.3 自动登录

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `AutomaticLogin`

## 简要描述

- 自动登录：自动登录条件，根据初始化企业微信接口，传递的vid，获取的uuid进行自动登录，如果初始化没有传递vid则自动登录失败，只要登陆过一次后期可以一直自动登录

## 请求URL
- `{host}/wxwork/automaticLogin`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|

## 请求示例

```
{
    "uuid": "00000000-0000-0000-0000-000000000000"
}
```

## 返回示例

```
{
    "data": null,
    "errcode": 0,
    "errmsg": "登陆成功"
}
```
