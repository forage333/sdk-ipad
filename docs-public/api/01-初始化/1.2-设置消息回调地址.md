# 1.2 设置消息回调地址

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `SetCallBackURL`

## 简要描述

- 设置消息回调地址

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|
|url |是  |String |消息回调地址|
|callbackType |是  |String |消息回调类型 HTTP  RABBITMQ|

```
//消息回调地址设置规则
//1. 搭建一个web服务
//2. 设定post请求接口，ContentType:"application/json" json请求方式
//3. 接收参数设置成对象，对象属性为以下属性
		{
			"uuid":"", //uuid 运行实例id
			"json":"", //回调消息内容为json格式
			"type": //消息类型
		}
```
