**SDK 方法**: `SearchContactByPhone`

## 简要描述

- 根据手机号搜索联系人

## 请求URL
- `{host}/wxwork/SearchContact`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

| 参数名 | 必选 | 类型   | 说明                                         |
| :----- | :--- | :----- | -------------------------------------------- |
| uuid   | 是   | String | 每个实例的唯一标识，根据uuid操作具体企业微信 |
