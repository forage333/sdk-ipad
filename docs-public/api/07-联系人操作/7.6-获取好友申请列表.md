# 7.6 获取好友申请列表

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `GetApplyUserList`

## 简要描述

- 获取好友申请列表

## 请求URL
- `{host}/wxwork/GetApplyUserList`

## 请求方式
- POST

- ContentType:"application/json"

## 参数

| 参数名 | 必选 | 类型   | 说明                                         |
| :----- | :--- | :----- | -------------------------------------------- |
| uuid   | 是   | String | 每个实例的唯一标识，根据uuid操作具体企业微信 |

## 请求示例

```
{
    "uuid":"00000000-0000-0000-0000-000000000000",
    "limit":100,
    "seq":0 //页码第一次传0 后续查询传返回的seq
}
```
