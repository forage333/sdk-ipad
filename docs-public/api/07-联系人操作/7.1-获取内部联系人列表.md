# 7.1 获取内部联系人列表

> [文档索引](../../README.md) · [API 总览](../README.md) · [返回目录](./README.md)

**SDK 方法**: `GetInnerContacts`

- **请求URL**: `/wxwork/GetInnerContacts`
- **参数**:

| 参数名 | 必选 | 类型 | 说明 |
|--------|------|------|------|
| uuid | 是 | String | 实例唯一标识 |
| limit | 否 | int | 每次返回数量 |
| strSeq | 否 | String | 查询下标，填返回的seq进行翻页 |
